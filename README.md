# World Countries Quiz

A rebuilt Flutter application that quizzes users on world capitals with multiple choice questions and instant feedback.

## Features
- Ten curated country questions with facts after each answer
- Progress indicator, score chip, and summary screen
- Restart button to practice as many times as you like

## Getting started
1. Install the Flutter SDK (3.3.0 or newer recommended).
2. Fetch packages:
   ```sh
   flutter pub get
   ```
3. Run on your desired device or Chrome:
   ```sh
   flutter run
   ```

## Web build
To produce a web bundle:
```sh
flutter build web
```
The output will appear under `build/web`.
